# AUREL storefront

## Run locally
```bash
npm install
cp .env.example .env
npm run dev
```

Set `VITE_API_BASE_URL` if the API is not running at `http://localhost:5000/api`.

## Experiences included
- AUREL editorial storefront
- VELL Studio eight-look styling collection
- Offcut ten-piece streetwear rail
- VirtualFit five-item spatial try-on
- Maison Vell six-look depth lookbook and twelve-piece product sheet
- Try the Look six-look runway carousel
- Blendy four-flavour smoothie slider

The frontend never collects card numbers or sends payment credentials. Checkout uses the backend's demo-only order endpoint.
